Flujo de una subida de avatar

1. Configavatar-profile.config.json define bucket, límites, tablas y roles.
→
2. SQL3 plantillas renderizan columnas, bucket/policies y RPC.
→
3. Core + SupabaseValida JPG/PNG/WebP ≤2 MB, construye la ruta y firma la URL.
→
4. ReactAvatar, useAvatarEditor y el modal con logout y PWA.
→
5. GuardarLa RPC apunta avatar_path; se borran el objeto anterior o el pendiente.

Los dos dueños (sin nombres de roles en la UI)

internalcuenta interna

Dueño auth_user_id sobre platform_usernames. Se abre desde “Mi perfil”.

<org>/internal/<auth_user_id>/avatar/<uuid>.<ext>
memberperfil de negocio

Dueño employee_id vía user_employee_links. Se abre desde su propio diálogo.

<org>/member/<employee_id>/avatar/<uuid>.<ext>

El preset connect-personnel usa pathLayout: "owner": <org>/<owner>/avatar/<uuid>.<ext>.
